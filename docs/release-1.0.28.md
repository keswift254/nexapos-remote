# NexaPOS 1.0.28

- The dashboard's refresh icon on Windows now does what it's meant to: instantly recompute today's figures from your local data. It no longer talks to the server, so it's never slow and no longer depends on the server being awake. (Automatic background sync with the server is unchanged and still runs on its own schedule.)

Windows and Android releases are cumulative. Installing this release does not require installing skipped versions first.
