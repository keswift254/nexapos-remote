# NexaPOS 1.0.83

Faster checkout from the keyboard, hints for the shortcuts, and a way back after a refund. Selling, stock, refunds, licences and the M-Pesa prompt are not changed.

- **Keyboard shortcuts in the cart.** F8 switches between Cash and M-Pesa Prompt. F9 (or Ctrl+Enter) finishes the sale: it completes a cash sale, or sends the M-Pesa prompt when M-Pesa Prompt is chosen. They work wherever the cursor is, and do nothing while a question box is open.
- **The cursor goes where you type next.** Choose M-Pesa Prompt (with F8 or the mouse) and the cursor is in the customer's M-Pesa number, ready to type. Choose Cash and it is in Cash received.
- **Hover to see the shortcut.** Rest the mouse on New Sale (F2), the cart (F4), the Home button (Alt+Home), the payment choices (F8) or the button that completes the sale (F9 or Ctrl+Enter) and it tells you the key. F1 lists them all.
- **After a refund you can always go back.** The refund receipt now has a back arrow and a Dashboard button. Before, it opened with nothing behind it, so the only way out was New Sale.
