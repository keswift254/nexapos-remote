# NexaPOS 1.0.31

**Android: this update needs a fresh install, one time only.** Tapping "Download & Install" will fail with "conflicts with an existing package" - that's expected. Uninstall NexaPOS first (long-press the app icon > Uninstall), then install this version fresh from the same download link. Your data is safe either way (nothing is deleted by uninstalling the app itself), but back up first from Settings > Backup if you want extra peace of mind.

Why: earlier versions were accidentally signed with different, unpinned keys at different points in this app's history, which is why some devices could never update past a certain version no matter how many times "Check for Updates" found something new. This release switches to one permanent signing key that will never change again - after this one-time reinstall, every future update will install normally, the way they're supposed to.

Windows is unaffected and updates normally as usual.

Windows and Android releases are cumulative. Installing this release does not require installing skipped versions first.
