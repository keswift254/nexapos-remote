# NexaPOS 1.0.59

Support conversation and Windows Hello follow-up release.

- Support messages can include up to 4 PNG/JPEG/WebP photos per message, up to 2 MB each and 4 MB total.
- Photos can be added from the picker or pasted from the clipboard, and remain private to the authenticated shop/support conversation.
- Support ticket lists and threads use cached data first so the Support screen opens quickly while fresh data loads.
- Customers can optionally add an email address for ticket updates; support replies can trigger email notifications.
- Dashboard support-reply notifications are dismissible and keep the unread badge/routing behavior.
- Support reply notifications open the relevant Support conversation instead of leaving the user on the dashboard.
- Windows Hello returns NexaPOS to the foreground reliably after authentication.
