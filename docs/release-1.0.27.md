# NexaPOS 1.0.27

- Local backup and Google Drive backup are now together under one **Backup** settings page.
- Fixed the dashboard's "Sync now" still being slow when multiple pending M-Pesa Prompt payments needed re-checking - they're now checked at the same time instead of one after another.
- The dashboard now tells you when a sync is taking a while because the server is waking up, instead of just spinning silently.
- Fixed an update download showing a raw connection error instead of a plain "check your internet and try again" message when the connection drops partway through.

Windows and Android releases are cumulative. Installing this release does not require installing skipped versions first.
