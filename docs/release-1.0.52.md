# NexaPOS 1.0.52

- Dashboard figures now refresh after every incoming LAN sync batch.
- Browser updates have a Download & Install button that fetches fresh application files, reloads, and resumes offline caching without deleting shop data.
- Windows starts maximized. Dashboard cards adapt to narrow screens and larger text.
- Keyboard controls: Esc goes back or closes a dialog, F1 shows help, F2 opens a new sale, F4 opens the cart, and Alt+Home returns to the dashboard.
- Verified legacy POS import totals, record relationships and repeated-import duplicate prevention against a real local source database.
