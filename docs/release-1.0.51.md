# NexaPOS 1.0.51

- **Wholesale now changes the prices in the cart.** Marking a sale as Wholesale re-prices the products already in the cart (and Retail puts them back), instead of only affecting products added afterwards. A product with no wholesale price set is sold at its retail price rather than for nothing. A cart left open from an earlier version works the same way.
- **Devices that joined a shop follow the shop's main device for the license.** If the main device's license expires or is revoked, the other devices of the shop now lock too - over the shop's network or through the internet - instead of carrying on with the days they were counting. A renewal reaches them the same way and reopens them. Both the main device and the joined devices need this version.
- **A main device whose license has ended stays on the shop's network** so the other devices hear about it.

All sales, sale items, expenses, payments, products, stock movements, users, roles, business settings, licensing safeguards, backup features, and prior fixes remain included. Android, Windows 10/11, and Windows 7/8 builds are cumulative. The installed POS is not modified by publication.
