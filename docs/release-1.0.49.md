- **A device that cannot open the app yet still hears about updates.** On the activation screen - a fresh install, or a license that has ended - NexaPOS now shows "Update available" with the new version and a Download & Install button right there, no license needed. It checks as soon as the screen opens.

All sales, sale items, expenses, payments, products, stock movements, users, roles, business settings, licensing safeguards, backup features, and prior fixes remain included. Android, Windows 10/11, and Windows 7/8 builds are cumulative. The installed POS is not modified by publication.
