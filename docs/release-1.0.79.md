# NexaPOS 1.0.79

Two fixes to the new Hold sale and Face ID features. Stock, reports, payments and licences are not affected.

- **The Held sales list is no longer cut off on a computer.** On a PC, laptop or tablet the list now opens as a centred window with a Close button, instead of a sheet stuck to the bottom of the screen where the taskbar covered part of it. Phones still get the sheet that slides up.
- **Face ID / fingerprint sign in on the web explains itself.** When the browser refuses to turn quick sign in on, the message now says why (not on the secure address, a browser that cannot do it, or a device with no Face ID, fingerprint or Windows Hello turned on) and ends with a short code. Turning Face ID or Windows Hello on and trying again now works without reloading the page.
