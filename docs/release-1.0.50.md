# NexaPOS 1.0.50

- **Tills on the same shop network now agree almost instantly.** A sale made on one device reaches the others in a fraction of a second over the LAN, even when the internet is slow or not working - a slow internet request no longer holds nearby devices up.
- **The dashboard turns over to the new day by itself.** After midnight "today" starts fresh without anyone tapping refresh, including after a computer that slept through the night wakes up.
- **A gentle reminder to set up quick sign in.** Where the device supports fingerprint, face or Windows Hello and it has not been set up, a banner offers to set it up in one tap. It can be dismissed and comes back after 72 hours.
- **A Lifetime plan.** Pay once and never expire - shown on the activation screen next to the other plans. Plans and prices are now managed by NexaPOS, so they can change without an app update.
- **Starting a payment can no longer spin without end.** If the device or browser is slow to respond, you now get a clear message and can try again - nothing is charged.

All sales, sale items, expenses, payments, products, stock movements, users, roles, business settings, licensing safeguards, backup features, and prior fixes remain included. Android, Windows 10/11, and Windows 7/8 builds are cumulative. The installed POS is not modified by publication.
