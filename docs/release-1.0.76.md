# NexaPOS 1.0.76

iPhone and iPad Home Screen fix for the web version. Nothing about selling, stock, licences or payments changes.

- **A Home Screen shortcut no longer surprises you with a new shop.** Since iOS 26, an icon added to the Home Screen opens as a separate copy of NexaPOS with its own, empty data (iPhone keeps it apart from Safari), so it asked you to set up a new shop. The "Add to Home Screen" steps now tell you to switch **Open as Web App** off, so the icon opens NexaPOS in Safari with your shop.
- **If you keep the Home Screen copy, joining your shop is one tap.** Its first screen now explains that its data is separate from Safari and has a **Join my existing shop** button. Enter an invite code from Safari (Settings > Sync & Invites > Invite a device) instead of setting up a new shop.

The Windows and Android apps are not affected.
