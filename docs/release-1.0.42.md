# NexaPOS 1.0.42

- Fixed "leave shop" (and normal syncing) taking a very long time, or appearing to hang, on a device with a large backlog of local-network sync data received from another device that has since left the shop or been disabled. This is now resolved with at most a handful of extra requests instead of one for every stuck record.
- The browser version's "Software Update" screen no longer shows a "Download & Install" button that could never work - it now says clearly that the browser version updates itself the next time the page is reloaded.
- The six-box authenticator code entry now focuses the first box automatically when it appears.

All sales, sale items, expenses, payments, products, stock movements, users, roles, and business settings remain included. Android, Windows 10/11, and Windows 7/8 builds are cumulative. The installed POS is not modified by publication.
