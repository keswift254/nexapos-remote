# NexaPOS 1.0.86

**Settings > M-Pesa Till Phone** in the Android, Windows and web versions (administrators) - the page NexaPOS Lite already had, for "M-Pesa Till/Paybill": the shop's own phone passes Safaricom's "payment received" messages on to NexaPOS so every till can check a customer's M-Pesa code.

- **Set up a phone** with your own password (the shop server checks it). The phone's key is shown once, with a code the phone's camera scans to open the set-up steps, and the address and key to copy by hand.
- **See the phones**, who added them and when each last passed a message on, and **remove** one (its key stops working at once).
- **Payments received** in the last 24 hours: who paid, the M-Pesa code, the amount, and whether it was used on a sale or archived. An archived payment can be **suggested at checkout again**.

Nothing else changes.
