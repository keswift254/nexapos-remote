# NexaPOS 1.0.90

**A till that stopped uploading ("A source revision was already recorded with different content") gets going again by itself.** A shop's PC had not uploaded for 27 days, with 4,590 changes waiting, and its LAN sync and dashboard suffered with it. The causes and what changed:

- **A sale no longer marks the product as edited.** The stock count (worked out on each till from the stock movements, which are what sync) used to move the product's "last changed" time: on every sale, and after every sync through a database safety net. A product sent again (after a LAN till relayed it, or after an answer was lost) then no longer matched the server's copy and was refused for good. It also meant that a price change made on another till could be ignored here as "older". Stock now changes only the count.
- **A change number the server already holds is renumbered, never set aside.** When a till's numbering went back (its data restored from an older copy) or a row changed under an old number, the refused rows were set aside, and once 500 were set aside, every upload of the till stopped. Now the till numbers every change it has not uploaded (and every one set aside for this reason by an earlier version) above the highest number the server holds for it, in the same order, and sends them again at once. What the rows say and when they were changed stay as they were, so each till still keeps whichever copy of a row is truly the newest. (The server says that highest number from 2026-11-23 on; with an older server the till renumbers row by row.)
- **The dashboard stays still while the till syncs.** It used to recompute on every write to the database, including sync bookkeeping, and to show a spinner (hiding its buttons) each time. Now only changes to the shop's data refresh it, at most once every 2 seconds, and the figures stay on screen while new ones are worked out.

**On a PC (any window 900 pixels wide or more) the dashboard fits on one screen.** New Sale, Inventory, Categories and Expenses are at the top, the four figures sit in one row, and the last-7-days chart below them: nothing needs scrolling. A phone or a narrow window keeps the page it had.
