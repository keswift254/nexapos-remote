# NexaPOS 1.0.38

- The Software Update screen no longer loses its download progress if you navigate away (e.g. back to the dashboard) and return - it keeps going in the background and picks up right where it was, instead of showing "Download & Install" again as if it had been cancelled.
- The Cart screen now has a search box and an "Add manual item" button at the top, so one more item can be added without leaving checkout.
- The cart's search box now searches by product name as well as barcode - typing a name shows a tappable list of matches, and scanning a barcode still works the same way.
- Fixed the cart's search box not responding on some devices/keyboards, and added a clear "No products found" message when nothing matches.

All sales, sale items, expenses, payments, products, stock movements, users, roles, and business settings remain included. Windows and Android builds are cumulative. The installed POS is not modified by publication.
