# NexaPOS 1.0.48

- **Buy a license from the activation screen.** Choose 3 months, 6 months, or 1 year and pay securely through Paystack with card or M-Pesa. NexaPOS checks the payment and activates the same device automatically—no license key needs to be typed.
- **Restore a paid license after reinstalling or changing devices.** Tap **Already paid? Restore my license**, enter the email used for payment, then enter the six-digit code sent to that address. The license moves securely to the new installation while keeping its original expiry date.
- **Your device ID is visible on the activation screen.** This makes support and license transfers faster when a customer needs help.
- **Offline shops sync over the local network promptly.** LAN discovery now runs on its own timer, so a sleeping or unreachable cloud server no longer delays changes between tills on the same network.
- **Update notifications are clearer.** The updater now shows only the version available instead of placing release-note text in the notification.

All sales, sale items, expenses, payments, products, stock movements, users, roles, business settings, licensing safeguards, backup features, and prior fixes remain included. Android, Windows 10/11, and Windows 7/8 builds are cumulative. The installed POS is not modified by publication.
