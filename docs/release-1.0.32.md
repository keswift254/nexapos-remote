# NexaPOS 1.0.32

Adds IntaSend as a new payment option in the cart, alongside Cash and M-Pesa Prompt. Tap "IntaSend" and enter the customer's M-Pesa number to send them a payment prompt directly - no checkout page to open, the app stays right where it is while you wait for confirmation.

A pending IntaSend payment (e.g. if the app is closed before the customer finishes paying) shows up in the same "Pending Payments" list as Paystack always has, so nothing gets lost track of.

Windows and Android releases are cumulative. Installing this release does not require installing skipped versions first.
