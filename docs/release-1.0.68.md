# NexaPOS 1.0.68

Small Support-screen improvement. Install it on every device; nothing about selling, stock, licences or payments changes.

- **One "+" button for photos.** In a support ticket (the reply box, and the form for a new ticket) the two buttons "Add photos" and "Paste photo" are replaced by a single **+** inside the corner of the message box. It opens the file chooser.
- **Paste a picture with Ctrl+V.** Copy a screenshot or picture, click in the message box and press Ctrl+V (Cmd+V on a Mac): it is attached to the message. Anything that is not a picture pastes as text exactly as before. On phones, a picture inserted from the keyboard is attached too.
- The photo rules are unchanged: up to 4 photos, 2 MB each, 4 MB in total.

This release does not change the licence, payment or database format. Windows 7/8 keeps its separate installer.
