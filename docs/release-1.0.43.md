# NexaPOS 1.0.43

- Fixed the join-shop screen briefly flashing back to the "join a shop" form right before opening after a shop's data finished downloading.
- Fixed "leave shop" (and "switch shop") sometimes needing several tries on an occasionally slow connection - a temporary failure is now retried automatically instead of sending the whole approval (and password entry) back to square one.
- Fixed the Windows installer sometimes not reopening NexaPOS automatically after installing an update, even though the update itself completed successfully.

All sales, sale items, expenses, payments, products, stock movements, users, roles, and business settings remain included. Android, Windows 10/11, and Windows 7/8 builds are cumulative. The installed POS is not modified by publication.
