# NexaPOS 1.0.63

Focused release based on the published 1.0.62 activation-reporting hotfix.

- Keep the 45-second activation timeout and visible error reporting.
- Add a Share button beside Save in the report PDF preview. It opens the device's share options for the generated PDF.
- Preserve the separate Windows 7/8 installer.

The activation change reports failures rather than repairing an underlying license or network fault. Preserve the client's installation and data while diagnosing the cause. This release does not include the pending support-storage changes or require their database migration.
