# NexaPOS 1.0.26

- Optional Google Drive backup: connect your own Google account from Settings to keep an extra encrypted copy of your automatic backups off-device, protected by a recovery passphrase only you know.
- New Sale's "Add manual item" dialog now submits on Enter from any field, same as clicking Add.
- Fixed a dashboard "Sync now" glitch where a slow-to-wake server could make the manual refresh silently time out and need a second click.

Windows and Android releases are cumulative. Installing this release does not require installing skipped versions first.
