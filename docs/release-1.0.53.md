# NexaPOS 1.0.53

- Native licensing now uses `https://license.nexapos.cc/index.php`.
- Native sync and payment-platform traffic now uses `https://sync.nexapos.cc/index.php`.
- Existing devices saved with the former Render platform URL migrate automatically to Namecrane while keeping the existing device API key.
- Custom platform addresses are preserved unchanged.
- This release does not require shop re-registration or a local data reset.
