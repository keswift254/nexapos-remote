# NexaPOS 1.0.74

Support improvements. Nothing about selling, stock, licences or payments changes.

- **An email address is now required on every support ticket.** In the app's Support screen the email field is no longer optional: a copy of every reply from support is emailed to it, so you also see the answer outside the app. The field starts with the address you used on your last ticket, so you rarely need to type it again.
- **Older versions get the same rule.** The support server now asks every app for an email address, so earlier releases also have to give one when opening a ticket (an older app that leaves it blank is served by the address its shop gave before).
- **Support chat on the website.** Visitors of nexapos.cc can now chat with support from a button on the page, with quick self-help answers first, photo attachments, and the same email copy of every reply. Those chats are answered from the same dashboard as the app's tickets.

This release does not change the licence, payment or database format. Windows 7/8 keeps its separate installer.
